Telechargement

              
Réglages yt-dlp

              
Regroupe les options globales utiles aux téléchargements YouTube et aux protections anti-bot.

            

            

              

                

                  

                    
Cookies navigateur

                    youtube
                  

                  
Option utile surtout quand YouTube demande une verification anti-bot pendant le telechargement.

                

                

                
                
Ajoute automatiquement --cookies-from-browser firefox a yt-dlp. Sert aux telechargements YouTube, pas a Qobuz.

              

              

                

                  

                    
Métadonnées intégrées

                    yt-dlp
                  

                  
Demande à yt-dlp d'écrire les infos disponibles directement dans le fichier téléchargé.

                

                

                
                
                
                
Activé par défaut. Les métadonnées viennent de YouTube/yt-dlp: titre, chaîne/uploader, date, URL et autres champs disponibles selon la source.

                
Si le recadrage échoue, le job conserve le fichier audio avec la cover originale et le signale dans les logs.

              

              

                

                  

                    
Format audio YouTube

                    music
                  

                  
Classe les formats natifs à tenter sans conversion, puis les formats convertis de secours.

                

                

                

                  
                  

                  
                

                

                  
                  
                

                
Les priorités natives ne ré-encodent pas l'audio. Les priorités converties utilisent ffmpeg via yt-dlp et servent de secours.

                

              

              

                

                  

                    
Nommage YouTube

                    fichiers
                  

                  
Choisis les éléments utilisés dans le dossier du média et dans le nom du fichier final.

                

                

                

                  
                  

                  
                

                
Par défaut: chaîne / auteur, date de publication, titre vidéo. Le champ Nom personnalisé d'un job reste prioritaire.

Pyannote

                      à préparer
                    

                    
Prépare le runtime Python dédié, colle un token Hugging Face si nécessaire, puis vérifie l’accès au pipeline `community-1` sans quitter l’app.

                  

                  

                  

                    
                    
                  

                  

                    

                      
                      
                    

                    

                      
                      
                    

                  

                  
Installe le runtime dédié, accepte le modèle community-1 sur Hugging Face, puis colle un token ou un chemin de pipeline local.

                  

                    Assistant pas à pas
                    

                      
1. Ouvre la page du modèle pyannote/speaker-diarization-community-1 sur Hugging Face et accepte les conditions d’accès.

                      
2. Crée un token d’accès sur hf.co/settings/tokens.

                      
3. Clique sur “Installer le runtime pyannote” pour créer le venv dédié et installer pyannote.audio.

                      
4. Colle le token ci-dessus, ou renseigne un clone local du pipeline comme fallback avancé.

                      
5. Clique sur “Vérifier l’accès” pour confirmer que le modèle est téléchargeable et prêt localement.
