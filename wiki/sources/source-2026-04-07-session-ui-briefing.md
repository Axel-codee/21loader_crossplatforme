## Informations durables extraites

- des captures d'ecran ne sont pas indispensables, mais elles aident fortement pour comprendre la densite, les espacements et les contrastes reels
- un bon brief UI pour ce projet devrait couvrir:
  - ce qu'il faut ameliorer
  - ce qui gene aujourd'hui
  - le style souhaite
  - les ecrans prioritaires
  - les contraintes techniques
  - quelques references visuelles
- contraintes deja posees dans l'echange:
  - conserver le HTML statique actuel
  - ne pas migrer vers un framework JS juste pour la refonte
  - garder un comportement responsive desktop + mobile
- `shadcn/ui` est pertinent comme reference de structure et de design system, mais pas comme solution technique directe dans l'etat actuel du projet
- Dribbble est utile pour l'inspiration visuelle, mais insuffisant seul pour juger une UX reelle
